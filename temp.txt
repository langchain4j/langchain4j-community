## Change
<!-- Please describe the changes you made. -->
Added a new `langchain4j-community-web-search-engine-deepseek` module.

- `DeepSeekWebSearchEngine` implements `WebSearchEngine` using DeepSeek's `POST /v1/tools/search` endpoint.
- Supports `query`, `count`, `ori_question`, `localization`, and `need_content`.
- Maps `title`, `url`, `snippet`, and `content` to `WebSearchOrganicResult`; exposes `summary`, `site_name`, `site_icon`, `date`, `rerank_score`, and `authority` as metadata.
- Supports synchronous and asynchronous search, configurable API key, base URL, timeout, and request/response logging.
- Added `DeepSeekWebFetchEngine` for DeepSeek's `POST /v1/tools/fetch` endpoint. Since langchain4j-core has no web fetch interface, it is a standalone engine rather than a `WebSearchEngine` implementation.
- Added unit tests and integration tests for both search and fetch. Integration tests are skipped when `DEEPSEEK_API_KEY` is not set.
- Registered the module in the root `pom.xml` and `langchain4j-community-bom/pom.xml`.
